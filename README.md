# Interview Prep Recall

Always-on-top Windows overlay that listens to a live interview call (Zoom, Teams, Google Meet, or
any app) and resurfaces the user's own prep notes at the moment they become relevant. Retrieval
only: it never generates talking points, it only recalls what the user already wrote.

Load prep notes and background context ahead of time, then get live recall, a talking-point
checklist, and a post-interview report during and after the call.

See `docs/interviewpreprecallprd.md` for the full product plan and
`docs/implementation/06-progress.md` for current build status.
